# 案例：小米汽车安全专场直播（安全体系）

一段 9 分 49 秒的真实直播（雷军、侯静雷、丁志、爽哥），拿来演示“会映”在真实素材上的效果：**直播里没人点我们任何人的名，8 个人里 7 个收到了内容不同的简报，1 个人没被打扰。**

字段沿用 `web/src/data/` 的结构和需求文档第 8 节的契约，现在已经是前端的主案例（见下文“已接进前端”）。

## 文件

| 文件 | 谁写 | 内容 |
|---|---|---|
| `case.json` | 手写 | 会议信息、视频、项目“竞品情报”、说话人映射和依据、转写纠错、章节、路由规则 |
| `people.json` | 手写 | 4 位说话人（真人）+ 8 位收件人（虚构），结构同 `Person` |
| `ledger.json` | 手写 | 20 条账本条目（只写原话，不写段号）+ 29 条路由，路由同时是评测标准答案 |
| `briefs.json` | 手写 | 7 份个人简报、1 人不打扰、分发人版 |
| `meeting.json` | 生成 | 前端用，结构同 `web/src/data/meetings.ts` 的 `Meeting` |
| `transcript.json` | 生成 | 后端输入，需求文档 8.1 |
| `gold.json` | 生成 | 评测用，8.2 条目 + 8.4 路由（snake_case） |

改了手写文件后重跑：

```bash
node data/cases/xiaomi-safety/build.mjs
```

脚本会解析 `data/小米汽车安全专场直播…【得到大脑】.md` 的“原文”部分，套上说话人修正和纠错，按原话给每条条目找到所在段落，再做校验。下面任何一项不过都会报错退出：

- 原话必须在转写里，且只命中一段
- 简报里的数字（facts、forYou、标题）必须能在原话前后两段里找到，防止模型复述错数字
- 路由只能发给收件人，不能发给真人说话人
- 简报和路由一一对应；有必读才推简报，没有就不打扰；每人 ≤ 60 秒；必读排在建议看前面
- 章节首尾相接、覆盖整段视频

## 人

**说话人（真人）**：只记录直播里自己说的或被介绍的身份，依据写在 `people.json` 的 `basis`。不给他们生成简报、不派任务，所有条目都只引用原话。开发计划 v0.1 第 3.3 节说“企业家发布会不用”，顾虑是替真人编台词，这一场就是这样避开的。

| id | 转写标签 | 依据 |
|---|---|---|
| `leijun` 雷军 | 说话人2、雷军 | 侯静雷回他“谢谢雷总”；00:19 一段被直接标成雷军 |
| `houjinglei` 侯静雷 | 说话人3 | “这方面工作了 22 年”，和开场介绍一致 |
| `dingzhi` 丁志 | 说话人4 | 被请来介绍全域安全之后开始发言 |
| `shuangge` 爽哥 | 说话人1 | 两次被点名“爽哥”后接话；全名和职务片段里没有，**不要补** |

**收件人（虚构）**：设定为一家虚构车企的竞品研究分发，8 个人：

| id | 角色 | 收到 |
|---|---|---|
| `hanzong` 韩总 | 总经理 | 5 条（管理者规则：目标、组织机制、投入规模） |

如果要换成别的收件人（比如准车主、媒体、门店），只需要改 `people.json` 的 recipients、`ledger.json` 的 routes 和 `briefs.json`，转写和条目不用动。

## 这一场能演示什么

- **场记**：转写把雷军拆成了“雷军”和“说话人2”，修正 2 处说错人的段落（00:02:37、00:06:00），人名热词“景雷 → 静雷”等 4 类纠错共 7 处，原文留在 `raw`。
- **路由**：没有 R1 点名、R2 角色，全靠 R3（负责的东西被提到）、R5（订阅）、R6（角色规则）。这正是“谁被提到就发给谁”做不到的。
- **审核官**：`xm_18`“应该是行业内首个”标了绝对化表述、待核实；`xm_08` 的 3500 人是爽哥说的，侯静雷才确认；`xm_02`、`xm_11` 标了“本段未覆盖”（电子安全、第三个事故预防团队）。
- **编辑官**：同一条“同档最安全”，对韩总是竞争目标，对江晚是定位口径，对邓凯是门店可能被问到的话。
- 本场全部公开内容，**没有受限条目**；权限闸用同周的内部会议演示（安全周会 `sf_07`：安委会编制和预算，受限）。

## 已接进前端（2026-10-31）

这一场现在是 `web/` 的主案例，原来的双 11 电商 mock 已经撤掉（在 git 历史里）。

- `web/src/data/meetings.ts` 直接 import `meeting.json`、录像 mp4 和 `poster.jpg`；`publisher`（发布者）= 江晚，`host` 仍是雷军。
- `web/src/data/run.ts` 是这一场的 20 秒分发剧本，简报直接读 `briefs.json`；江晚拿 `hostBrief`（发布者版）。
- 同一家虚构车企本周还有三场内部会议（安全周会、车主运营月会、门店销售周会，人和话都是虚构的），和直播互相印证：一票否决 vs 我们没有否决权、座椅夹手、484 场培训 vs 60 多场、699 元表盘 vs 权益对比表。
- 收件人加了职级（L1 高管 / L2 部门负责人 / L3 组长 / L4 成员）、部门、汇报线；新增两位 L4 成员林夏（江晚组员）、唐川（宋岚组员），只出现在内部会议里，不改这一场的路由和金标。
- 回放页播放真录像（竖屏放在共享屏右边），跟逐字稿、账本、时间轴同步。
- 字级时间是按段内均匀分布估的，和 `derive.ts` 的 `charTime` 一致；后端接入 ASR 后换真实时间戳。
